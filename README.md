# Jeweler 3D Community

Open source jewelry design tools for Blender.

## Features

- **Ring & Size** — create ring size references and profile-based shanks.
- **Gems** — add gemstone meshes with supported cuts, stones, and sizes.
- **Prongs** — create and readjust prongs on a selected gemstone.
- **Cutters** — add a procedural seat and hole cutter to selected gems.

## Installation

In Blender, open **Edit → Preferences → Get Extensions**, search for **Jeweler 3D Community**, and install it. To install from a local ZIP, use **Install from Disk** in the same preferences window.

## Requirements

- Blender 4.2.0 or newer
- Windows, macOS, or Linux
